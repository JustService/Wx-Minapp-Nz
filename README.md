# Wx-Minapp-Nz

「招生服务微信小程序」工程仓库，包含规格文档、后端示例实现以及微信小程序端代码。

## 仓库结构

- `docs/`
  - `CODEX_SPEC.md`：工程规格主入口（需求与页面说明）
  - `openapi.yaml`：OpenAPI 3.0 接口契约（接口约定与字段定义）
  - `schema.mysql.sql`：MySQL 8.0 建表 DDL
  - `acceptance.md`：MVP 验收用例（测试清单）
  - 其他：变更记录、原始 PRD 等

- `backend/`
  - 使用 PHP 实现的轻量后端骨架（路由、控制器、服务等），可基于 `docs/openapi.yaml` 和 `docs/schema.mysql.sql` 继续扩展为正式服务端。

- `minapp/`
  - 微信小程序工程目录，当前已实现的主要能力包括：
    - 底部 5 个导航入口（首页 / 测评 / 成长 / 权益 / 我的），支持图标与文案选中高亮的自定义 tabBar。
    - 首页：顶部资源条（头像、昵称、等级、积分、抽奖券红点）、主线任务卡（首测评 → 报告 → 预约/预报名）、四宫格快捷入口（测评/成长/权益/学校介绍）、活动/公告卡片等。
    - 测评中心：按主题分组/筛选（学科/性格/习惯/校园偏好）、测评卡片展示用时、奖励（积分/徽章）、状态徽章（未完成/已完成/可复测），采用大圆角卡片列表布局。
    - 成长模块：标签体系（兴趣/学习/校园/习惯）、推荐卡片流（喜欢/跳过/屏蔽、展示推荐理由），互选后解锁组队任务与预设招呼语，并预留风控入口（举报/拉黑/屏蔽）。
    - 权益模块：顶部积分余额与「去兑换」入口，积分商城 / 抽奖活动 / 权益背包模块，以及展示名称、有效期与状态（可用/已用/过期）的权益券卡片。
    - 我的页面：一屏展示等级/积分/券数量，入口包括预报名信息、报告历史、隐私设置与联系方式，文案强调面向未成年人的最小化收集与可撤回/删除。
  - 详细页面结构与交互以 `docs/CODEX_SPEC.md`、`docs/acceptance.md` 为准。

- `admin/`
  - 预留的后台管理端目录，尚未实现具体业务代码，可按 `docs/CODEX_SPEC.md` 与 `docs/openapi.yaml` 自行扩展。

## 小程序本地运行说明

1. 安装并打开微信开发者工具。
2. 选择「导入项目」，将项目根目录设置为本仓库下的 `minapp/`。
3. 使用你自己的小程序 AppID 或测试号 AppID。
4. 导入后即可在开发者工具中预览「首页 / 测评 / 成长 / 权益 / 我的」等页面，并验证 tabBar 高亮、积分权益、测评流程、成长推荐等功能表现。

## 后端与联调

- 后端可在 `backend/` 目录下按需补全，实现与 `docs/openapi.yaml` 中约定接口的一致联调。
- 如需要持久化数据，可基于 `docs/schema.mysql.sql` 初始化数据库结构，再在现有 PHP 骨架上接入实际存储。
